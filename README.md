# 픽셀 치즈 백과 · Pixel Cheese Encyclopedia

A small Korean-language cheese encyclopedia in a clean, muted pixel-art style.

- 28 cheeses (France 11, Italy 8, and 7 more countries), each with a hand-drawn 16×16 pixel icon
- Search plus filters by milk, texture and country
- Pixel map of cheese origins centered on France; click a pin to filter
- Detail popup with aging, fat, history, how to eat it, pairings and a fun fact
- Cheese history timeline, how cheese is made, storage tips
- Light/dark theme

Open `index.html` in a browser. It is a single self-contained file; the Galmuri pixel font loads from jsDelivr.

`parts/` holds the raw content data that is inlined into `index.html`.
